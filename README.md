# Pokémon GO Tracker Mobile

Versão web responsiva/PWA. Publique estes arquivos no GitHub Pages.

1. Crie um repositório no GitHub.
2. Envie `index.html` e `manifest.json` para a raiz.
3. Em Settings > Pages, escolha Deploy from a branch e a branch `main`.
4. Abra o endereço gerado no celular.
5. No Android/Chrome, use "Adicionar à tela inicial".

Os dados da coleção ficam no armazenamento local do navegador. Use o menu Backup para exportar/restaurar JSON.
