PokéTracker GO v3

- PWA pronta para Android quando publicada em HTTPS.
- Carrega 1025 espécies e dados de formas/costumes da base pública WatWowMap/pogo-data-api.
- Categorias: Shiny, Shadow, Purified, Lucky, 100%, Mega, Dynamax, Gigamax, costumes, regionais, Unown, lendários, míticos, ultracriaturas e tamanhos XXS/XS/Normal/XL/XXL.
- A coleção fica salva no armazenamento local do navegador.

Instalação Android: publique estes arquivos em um endereço HTTPS; abra no Chrome; menu ⋮ > Adicionar à tela inicial/Instalar aplicativo.
